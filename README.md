### 与专业机构备考框架的对照

本计划的四阶段结构与主流机构官方备考体系同构，可放心执行：

- **粉笔系统班四阶段**：基础精讲 → 专项刷题 → 重难点拔高 → 模考冲刺（[新华报业报道](https://www.xhby.net/content/s6ad07fd5e4b0cd8a3759469d.html)）⟷ 本计划：筑基(D1-40) → 提速(D41-65) → 真题(D66-90) → 冲刺(D91-100)
- **华图备考路径**：基础 → 强化 → 刷题 → 预测冲刺（[华图官网备考指导](https://www.huatu.com/2025/0918/2833406.html)、[湖北华图三个月备考计划](https://hb.huatu.com/gjgwy/1150996.html)）⟷ 阶段划分一致，且本计划额外内置了「错题回炉日」「数据诊断日」等复盘节点
- **学习顺序**：资料分析优先（性价比最高）→ 判断推理（确定性高）→ 言语（题量大）→ 申论贯穿 → 数量策略性取舍，符合各机构对在职备考者的通用建议

### 关键考试时间节点（以官方公告为准）

- **2027年度国考**：报名 2026-10-14 8:00 至 10-24 18:00（[bm.scs.gov.cn/kl2027](http://bm.scs.gov.cn/kl2027)），笔试近年多在11月下旬。
- **省考联考**：多数省份次年1-2月报名、3月前后笔试。
- **本计划定位**：100天完整覆盖省考联考周期；符合条件报名了2027国考的，可将其作为全真实战演练，重心放在省考。

## 二、每天 2-3 小时的时间节奏分配（在岗志愿者黄金时间表）

在西部计划服务期间，白天多有基层行政工作或下乡走访，**切忌疲劳战，要抓整块深度学习与碎片化记忆结合**：

1. **晨间/上班前（07:30 - 08:00，约 30 分钟）**：
   - 朗读/速记：李梦娇常识口诀 / 申论官方时政金句 / 高频成语辨析。
   - 手机练习：粉笔 APP 做 10 组资料分析速算练习（乘除法、截位训练）。
2. **晚间黄金深度学习（19:30 - 22:00 或 20:00 - 22:30，整块 2.5 小时）**：
   - **前 60 分钟**：模块权威网课精讲（建议 1.25x~1.5x 倍速，针对性做考点框架笔记）。
   - **中 60 分钟**：跟套闭卷专项限时刷题（粉笔 5000 题精做 20-30 题）。
   - **后 30 分钟**：错题彻底复盘，分析错误选项设置陷阱，填入本打卡系统的错题心得中。
3. **周末/双休日（按考场作息强化模考）**：
   - 周六上午 09:00 - 11:00 全真模考行测；下午 14:00 - 17:00 手写申论真题。

## 三、100 天四阶段科学备考路线图

- **阶段一：基础筑基·模块逐个击破（Day 1 - Day 40）**
  - Day 1-11：资料分析核心突破（速算技巧、基期现期、两期比重、平均数、混合增长）
  - Day 12-25：判断推理体系搭建（图形位置样式属性数量、定义拆解、类比逻辑、翻译推理、削弱加强）
  - Day 26-35：言语理解逻辑重塑（中心理解转折因果对策、细节判断偷换套路、逻辑填空语境呼应与高频词）
  - Day 36-40：申论基础题型入门（审题五要素、归纳概括提炼采分点、综合分析逻辑结构）
- **阶段二：强化提速·专题攻坚与真题动笔（Day 41 - Day 65）**
  - Day 41-47：申论解决问题/对策题、应用文贯彻执行公文写作规范精讲
  - Day 48-54：申论大作文议论文立意、分论点论证、基层实际素材结合与论据积累
  - Day 55-60：数量关系花生十三 5 大高频必拿题型精讲（工程、利润、行程、容斥、排列组合）
  - Day 61-65：行测三大核心模块（资料/言语/判断）限时组合刷题与提速技巧
- **阶段三：真题攻坚·全真模考与深度复盘（Day 66 - Day 90）**
  - 精刷近 6-8 年国考行政执法/地市级真题卷及目标省份省考真题卷
  - 严格限时做题，建立错题漏洞账本，申论大题逐篇动笔手写并对照标答改写
- **阶段四：考前冲刺·时政速记与答题策略固化（Day 91 - Day 100）**
  - 李梦娇常识口诀闭环扫描，近半年重大时政核心考点汇总
  - 错题盲区最后一遍清理，固化考场个性化答题顺序与涂卡节奏
  - 西部计划定向岗资格复审材料清单梳理与心理调适

## 四、打卡系统网站使用说明

本项目已为你构建了一套**纯前端（HTML + CSS + JS）、零依赖、现代极简风格**的本地学习打卡 Web 系统：

- **文件构成**：
  - `index.html`：网站主页面（双击即可在 Chrome/Safari/Edge 中打开，手机与电脑自适应）。
  - `style.css`：现代极简设计系统（浅色/深色护眼主题、进度环、卡片动效）。
  - `app.js`：100 天全量计划数据（每天含知识点、时间分配、名师课程、刷题书目、行动清单、自测问答、西部计划贴士）+ 打卡持久化与专注计时器。
- **核心功能**：
  - **今日聚焦**：左侧卡片突出显示当天要做的事——核心考点、时间分配（网课/刷题/复盘分钟数）、名师课程与书目、当日 Checklist、即问即答自测、错题随笔本地自动保存。
  - **100天日历与列表视图**：自由切换，支持按阶段（筑基/提速/真题/冲刺）与科目模块组合筛选；「定位至今日」一键跳回当天。
  - **打卡与统计**：完成打卡后进度环、已完成天数、累计学习时长自动更新；数据保存在浏览器 localStorage。
  - **专注计时器**：25/45/60 分钟三档番茄钟，自动记录今日专注时长。
  - **速查宝典与政策指南**：内置资料分析核心公式、判断推理秒杀模型、申论答题黄金法则，以及西部计划考公政策要点（弹窗形式）。
  - **数据备份与迁移**：右上角一键导出 JSON 备份，换电脑/换浏览器时导入即可无缝延续。
- **每日节奏建议**（与计划中的时间分配一致）：
  1. 晨间 30 分钟：口诀背诵 + 粉笔APP速算练习（碎片时间）。
  2. 晚间整块 2-2.5 小时：网课精讲（1.25-1.5 倍速）→ 限时刷题 → 错题复盘并写进打卡随笔。
  3. 周末：按计划完成全真模考日（Day 40/52/53/65/77/88/97 等高强度日建议安排在周末）。
